# البوصلة — مساعد التاجر داخل تسيير

> البوصلة ما تعدكش — ترسم المسار.

تطبيق تسيير (Custom App) يصنّف كل منتج بالمرحلة، يحسب الربح الحقيقي (كاش / عند شركة التوصيل / محبوس في السلعة)، يتبّع الستوك والتعمير، يرسم منحنى «ترايدينغ» لكل منتج وللبيزنس، يعطي الروافع والتحذيرات بالدينار، ويبعث تقرير كل صباح على 08:00.

بلا حتى dependency: Node 20+ برك.

```bash
npm run demo          # http://localhost:8787 بالبيانات التجريبية
npm test              # اختبارات القبول الـ 12 (الـ 12 يحتاج Chromium/Playwright؛ SKIP_UI=1 باش تفوتو)
npm run report:tests  # يكتب docs/TEST_REPORT.md بالأرقام اللي خرجت
```

## التركيب
| الملف | الدور |
|---|---|
| `engine/engine.js` | **المحرّك (عقل واحد)**: الصيغ، الحالات الثلاث، 300 سيناريو، سقف السوق، رأس المال يوم بيوم، الستوك، المراحل، المنحنى، الروافع، التحذيرات، `analyzeBusiness()` |
| `engine/report.js` | التقرير اليومي بالترتيب المكتوب، من نفس snapshot تاع الشاشات |
| `engine/format.js` | مليون / مليار / دج، الأرقام LTR |
| `server/server.js` | الصفحة + API + webhooks + الجدولة (04:00 سحب، 08:00 تقرير، كل ساعة 🛑/🔴 برك) |
| `server/webhooks.js` | Ed25519 + حذف المكرّر بـ `webhook-id` |
| `server/tassyir.js` | عميل API (المسارات في جدول)، كتابة التاغ بلا مسح القدام، أسباب الرجوع `#R-01…10` |
| `server/actions.js` | خطر قليل ← يتدار؛ خطر كبير ← بطاقة موافقة |
| `web/` | الواجهة RTL، عمود واحد في التيليفون |
| `demo/data.js` | بيانات تجريبية (مكتوب عليها «تجريبية») |

## الإعداد (حساب حقيقي)
| المتغيّر | |
|---|---|
| `TASSYIR_API_URL`, `TASSYIR_TOKEN` | بلاهم يخدم بالبيانات التجريبية |
| `TASSYIR_WEBHOOK_PUBLIC_KEY` | المفتاح العام Ed25519 (base64 ولا PEM) |
| `BOUSSALA_DATA` | ملف بيانات التطبيق المحلية |

## قرارات تفسير (مكتوبة باش تتراجع)
- **الستوب** يتقاس على «الكاش + عند شركة التوصيل»، ماشي الكاش وحدو: مع سحب 14 يوم، كل منتج جديد يكون تحت الصفر بالكاش حتى ولو رابح. الخط الحقيقي في المنحنى يبقى كاش فقط.
- **المخروط** يحسب التكاليف نهار التوصيل والكاش نهار السحب، كيما الخط الحقيقي.
- **الستوب المتحرّك**: الليد على 3 أيام فات أغلى ليد بالتوصيل الأسوأ.
- **كرياتيف مات**: الليد آخر 7 أيام فوق 21 يوم اللي قبلهم بـ 10% (`creativeDeadMargin`، حطّها 0 للقراءة الحرفية).
- **السحب أسرع**: الأثر في النهار = رأس المال اللي يتحرّر × مردود الدينار في النهار من نفس الخطط.
- العتبات كامل في `DEFAULT_POLICY` وتتبدّل لكل بيزنس (`business.policy`) بموافقة التاجر.
- الـ API: شكل المسارات والحقول افتراض حتى تأكّدو تسيير — كلش في `ENDPOINTS` و`server/live.js`.
