# My Mind OS

نظام شخصي واحد لتنظيم الأفكار والمشاريع والمصادر والمهام — من **فكرة → تنظيم → قرار →
مشروع → مهمة → تنفيذ → نتيجة → تعلّم → فكرة جديدة**. مصمّم لمنع التشتت، بمشروع نشط
واحد فقط وخطوة تالية واضحة دائمًا.

> منصة شخصية خاصة (single-user). ليست SaaS ولا متعددة المستخدمين.

## الحالة: Milestone 1 — Foundation

هذه أساسات المشروع فقط: السقالة، المصادقة، الجداول + RLS، لوحة تحكم فارغة، واختبارات
أساسية. لا يوجد بعد: تحليل AI فعلي، صفحات Inbox/Projects/Knowledge/Content الكاملة.

## المتطلبات

- Node.js 20+ (طُوِّر على 22)
- حساب Supabase (Postgres + Auth)

## الإعداد

```bash
npm install
cp .env.example .env.local     # املأ مفاتيح Supabase الحقيقية
npm run dev                    # http://localhost:3000
```

يعمل التطبيق محليًا حتى بدون مفاتيح Supabase (يستخدم قيمًا بديلة آمنة)، لكن تسجيل الدخول
الحقيقي والبيانات يتطلّبان مفاتيح فعلية في `.env.local`.

## قاعدة البيانات

Migrations في `supabase/migrations/`. طبّقها عبر Supabase CLI:

```bash
supabase db push
```

- `0001_init.sql` — الجداول الثمانية، الفهارس، الحذف الناعم، قيد «مشروع نشط واحد»،
  ومشغّلات `updated_at`.
- `0002_rls.sql` — تفعيل RLS وسياسات العزل حسب المالك على كل جدول.

## البنية

انظر [`ARCHITECTURE.md`](./ARCHITECTURE.md) لتفاصيل الطبقات، نموذج البيانات، ونموذج الأمان.

## الأمان

- كل جدول محميّ بـ RLS: يرى المستخدم بياناته فقط (`owner_id = auth.uid()`).
- لا يُكشف أي مفتاح خدمة في الواجهة. القيم العامة فقط تبدأ بـ `NEXT_PUBLIC_`.
- كل استدعاء AI (لاحقًا) يمرّ عبر Route Handler على الخادم، لا من المتصفح.
