# قاعدة 1: الريل الشارح (مرجع: rakan.builds، 92s)

> **هذي هي القاعدة اللي نكتبو ونصمّمو عليها كل ريل شارح، في كل حساب.** كل رقم هنا مقاس من الفيديو الأصلي frame بـ frame (30fps) وبتحليل الصوت. التفاصيل الخام في [`01-analyse-reel-rakan.md`](01-analyse-reel-rakan.md) و [`03-timing-transitions-sfx.md`](03-timing-transitions-sfx.md).
>
> **المؤشرات تاع المرجع:** 11.4K لايك • 8,400 تعليق • 16.3K مشاركة • أول فيديو في الحساب.

---

## 1. الهيكل (الميزانية بالوقت)

| الجزء | المرجع (s) | % من المدة | واش يدير |
|---|---|---|---|
| **Hook** | 0 → 7.7 | 0–8% | عدو + قيمة بالرقم («كورس بـ 1,875») + وعد بوقت («أعطني 60 ثانية») |
| **فصل 01** | 7.7 → 12.0 (4.3s) | | فعل واحد |
| **فصل 02** | 12.0 → 21.8 (9.8s) | | فعل واحد، الصورة تتبنى (مجلد ← 3 فروع) |
| **فصل 03** | 21.8 → 27.8 (6.0s) | | فعل واحد |
| **فصل 04** | 27.8 → 42.1 (14.3s) | | أطول فصل: قائمة 5 عناصر (1/5 → 5/5) |
| **فصل 05** | 42.1 → 47.2 (5.1s) | | يحيد العائق («ما تثبّت شيء») |
| **فصل 06** | 47.2 → 58.3 (11.1s) | | **الفكرة اللي تفرّق** (الذوق) |
| ⚡ **Interrupt** | 58.3 → 60.4 (2.1s) | **63%** | جملة وحدة، لون معاكس |
| **فصل 07** | 60.4 → 73.8 | | النتيجة + مثال تعديل حي («قل له كبّر العنوان» ← ✓ تم التعديل) |
| **Recap** | 73.8 → 81.4 | 80–88% | «من **مجلد فاضي** إلى **ريل جاهز**» + «الأدوات تمنتج، و**ذوقك** يصنع الفرق» |
| **CTA** | 81.4 → 87.7 | 88–95% | «اكتب **EDITOR** في التعليقات» ← DM + تابعني + open loop |
| خاتمة | 87.7 → 91.8 | | cut + صوت ختام |

**القوانين:**
1. **5 حتى 7 فصول**، كل فصل = **فعل واحد ولا فكرة وحدة**. المدة 4–15s (median ≈ 9s).
2. **Interrupt واحد برك** بين 55% و65% من المدة، على **الفكرة اللي تفرّق** (ماشي على خطوة تقنية).
3. **آخر فصل يوري النتيجة**، ماشي يشرح.
4. **الـ Recap = تحوّل:** «من X إلى Y» (X بسيط/فارغ، Y جاهز).
5. **الـ CTA = كلمة مفتاح + هدية + متابعة + open loop.** (في الحساب الشخصي: سؤال مستقطب بلاصة الكلمة المفتاح.)
6. **المدة عندنا:** 45–65s. المرجع 92s طويل (قال «60 ثانية» وكمّل 92، وهذا ما نعاودوهش).

## 2. كتابة السكريبت

| القاعدة | الرقم |
|---|---|
| السرعة | **2.6 كلمة/ثانية**، يعني 130 كلمة لـ 50s و 230 كلمة لـ 90s |
| الجملة | ≤ 8 كلمات. أفعال أمر (حمّل، افتح، أنشئ، اختار، اكتب) |
| «كيفاش» مقابل «علاش» | 90% كيفاش. «علاش» مرة وحدة: في الـ interrupt |
| الكلمة الملوّنة | **وحدة في كل جملة**: الكلمة اللي لو تسمعها وحدها تفهم الجملة |
| العنوان على الشاشة | **ماشي** نفس الكلام. سطر 1 = تصريح (2–3 كلمات + نقطة). سطر 2 = اللفّة (2–4 كلمات + نقطة). مثال: «مجلد واحد. / ثلاث مجلدات.» |
| الأرقام | تتقال **وتبان** في نفس اللحظة (60، 5/5، 1,875) |
| الصمت | 0. ما كانش حتى وقفة > 0.25s قبل الخاتمة |
| الكذب | 0. كل رقم من مصدر (الأداة، الكتاب، تسيير). «مثال، ماشي وعد» كي يكون مثال |

## 3. الشاشة (1080×1920)

| المنطقة | y (px) | المحتوى |
|---|---|---|
| شريط علوي | 100–170 | **التقدّم** (خطوط = عدد الفصول) يسار • **بادج الفصل** «02 · المجلد» يمين |
| العنوان | 250–520 | سطر 1 عريض (أبيض/أسود) + سطر 2 بلون البراند وخط مميز |
| الـ Visual | 560–1180 | رسم واحد يتبنى (مجلد، قائمة، عدّاد، تايملاين، كارت) |
| الترجمة | ≈1250 | 1–3 كلمات، كلمة ملوّنة |
| الأفاتار | 1390–1610، يسار | دائرة ≈220px، تعابير تتبدّل مع المعنى |
| **ممنوع** | تحت 1620 • يمين 940 | واجهة إنستغرام/تيك توك |

- **البادج يختفي** في الـ Recap والـ CTA.
- **الأفاتار:** في الركن طول الفيديو. **يطلع بالجسم كامل مرة وحدة** (في الـ recap، يدّيه مكتّفين). وفي الـ CTA يقعد حدا الـ @handle + زر «تابعني».
- خلفية بلون واحد + grid خفيف. **لونين برك:** لون البراند + لون التظليل.

## 4. الحركة

| العنصر | القاعدة |
|---|---|
| **Wipe بين الفصول** | 9 frames: panel بلون البراند يدخل من اليمين، يغطي في frame 4، يخرج من اليسار. الفصل يتبدّل تحتو |
| قبل الـ wipe | البادج والعنوان القديم يبهتو ≈0.15s قبل |
| **العنوان** | سطر 1 مباشرة بعد الـ wipe؛ سطر 2 يطلع مع الكلمة في الصوت (≈0.4–1s من بعد) |
| **Visual** | عنصر جديد كل **1–2s** (≈0.8 حدث/ثانية). قائمة: عنصر كل ≈1s مع ✓ وعدّاد n/N |
| **Interrupt** | المشهد يبهت **8 frames** ← **cut** لشاشة لون معاكس ← الجملة تطلع |
| **الترجمة** | **كلمة بكلمة** كل **0.33s** (0.23–0.43)، كل كلمة **pop 6 frames** |
| الأفاتار | تعبير جديد على كل تحوّل في المعنى (يخمّم، يتفاجأ، يغمز في الأخير) |
| Easing | spring خفيف / ease-out. بلا glitch ولا zoom عنيف |

## 5. الصوت

| | القاعدة |
|---|---|
| المستوى | **‎-14 LUFS** integrated، LRA ≈3 (مضغوط، ثابت) |
| الموسيقى | bed خفيف طول الفيديو؛ **تسكت 0.3s قبل الـ interrupt** |
| **القاعدة الذهبية** | **الصوت يسبق الصورة بـ 0.3s** |
| Whoosh | كل wipe: 0.6–0.9s، attack ≈0.3s، فوق 6.5kHz (`sfx/ours/whoosh.wav`) |
| Whoosh كبير | الخروج من الـ interrupt: يبدا 0.56s قبل (`whoosh-big.wav`) |
| Boom | الدخول للـ interrupt (`boom.wav`) |
| Pop / Tick / Typing | عنصر يدخل / عنصر في قائمة / نص يتكتب (`pop` `tick` `typing`) |
| Sting | بعد آخر كلمة (`sting.wav`) |

## 6. الـ CTA (علاش 8,400 تعليق)
- **كلمة وحدة، قصيرة، بالحروف الكبار على الشاشة** (EDITOR).
- **الهدية تكون أداة** (برومبتات، حاسبة، PDF)، ماشي «باقي الشرح».
- DM أوتوماتيكي (ManyChat) **لازم يكون مفعّل قبل النشر**.
- **تبدّل الكلمة والهدية كل أسبوع** (باش ما يولّيش bait).

## 8. Checklist قبل الـ render
- [ ] Hook فيه رقم ولا سعر ولا عدو في أول 3s
- [ ] 5–7 فصول، كل واحد فعل واحد، بادج + شريط تقدّم
- [ ] كلمة ملوّنة وحدة في كل جملة
- [ ] Interrupt واحد بين 55–65%
- [ ] عنصر جديد في الـ visual كل 1–2s
- [ ] Recap «من X إلى Y»
- [ ] CTA: كلمة مفتاح + هدية (DM مفعّل) + open loop
- [ ] كل رقم عندو مصدر؛ «مثال» مكتوب كي يكون مثال
