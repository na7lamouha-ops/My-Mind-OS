# EDPROD — فريق إنتاج فيديوهات الدورة

فريق وكلاء Claude Code لتصميم وإنتاج فيديوهات ecommanita × tassyir (ريلز، تيزرات، حلقات السلسلة).

## الفريق (`.claude/agents/`)
| الوكيل | الدور |
|---|---|
| **edprod** (سكيل، `/edprod`) | **المخرج**: يقود الخدمة ويوزّعها، ما يولّد حتى يتأكد السكريبت |
| `edprod-writer` | الكاتب: كوبيرايتينغ بالدارجة، هوك، نيوماركتينغ، سكريبت بالتوقيت |
| `edprod-researcher` | المحقق: يدقق التاريخ والأرقام والمصطلحات |
| `edprod-designer` | المصمم: بريف بصري، safe zone، البراند، تقسيم الطبقات والإحداثيات |
| `edprod-motion` | الموشن: يكتب ويشغّل سكريبت الريندر (Python/ffmpeg) |
| `edprod-sound` | الصوت: جمهور حقيقي CC0، مؤثرات، مزج ‎-14 LUFS |
| `edprod-reviewer` | المراجع: QC، أخطاء، حقوق، تصدير Meta/TikTok |

## طريقة الخدمة
1. **الفكرة** + البوستر/الطبقات ← المخرج يحدد النوع والمدة والمقاس.
2. **الكاتب + المحقق** ← سكريبت مشهد بمشهد (الوقت · الصورة · الكتابة · الصوت) ← **تأكيد صاحب الدورة**.
3. **المصمم** ← بريف بصري + إحداثيات العناصر في البوستر.
4. **الموشن + الصوت** ← **تجربة 10 ثواني** ← ملاحظات.
5. الكامل ← **المراجع** ← MP4 جاهز للنشر (+ غلاف).

## الملفات
- `BRAND.md` الألوان، الخط، الـ safe zone، القواعد.
- `GLOSSARY.md` قاموس الدورة والماتش والثورة.
- `assets/` الخطوط، طبقات المانيطة واللوغو، بوستر الماتش، رصاصة ECOMMANITA، صوت hook5 التاريخي، أصوات جمهور CC0.
- `tools/lib/edprod_kit.py` الدوال المشتركة (نص عربي، تركيب، وهج، إنكودر، مكسر، جمهور).
- `tools/export.sh` التصدير النهائي (‎-14 LUFS، QC، غلاف).
- `tools/bullet_sprite.py` يولّد رصاصة محفورة بأي اسم.
- `tools/examples/` السكريبتات الحقيقية اللي خرّجنا بيها: الماتش، التيزر v4، المراية، اللوحة التكتيكية، مونتاج الصوت التاريخي.
- `projects/<اسم>/` مجلد لكل فيديو (سكريبت، بريف، ريندر، المخرجات).

## المتطلبات
`ffmpeg`، Python 3 مع `numpy scipy pillow` (و`libraqm` للعربية)، Node (اختياري لـ render-qc).

## الحدود
- ما كاينش توليد صوت بشري (المعلّق يتسجّل) ولا توليد صور AI.
- في بيئة السحابة، GitHub برك مفتوح: كل الأصول لازم تكون في `assets/`.
- الوكلاء ما يسمعوش الصوت: يقيسو (LUFS، spectrogram)، والحكم النهائي لصاحب الدورة.
