# كيفاش تستعمل الباك مع ChatGPT

1. حل ChatGPT (موديل تاع الصور، GPT-4o ولا أحدث).
2. ارفع **كامل الملفات** اللي في `1-references` و`2-brand` (11 صورة).
3. انسخ البرومبت كامل من `0-PROMPT-ChatGPT.md` (من بعد الخط) والصقو، وابعث.
4. يعطيك **الفرايم 01** برك. إذا عجبك الستايل، قولّو: `Perfect, continue with frame 02` وكمّل وحدة بوحدة حتى 08.
5. إذا بدّل اللوقو ولا خسرو، قولّو: `Leave the banner/screen blank, no logo` وأنا نحطّو بيدي (القاعدة تاعنا: الذكاء الاصطناعي ما يرسمش اللوقو).
6. إذا كتب حروف في الصورة، قولّو: `Remove all text from the image`.
7. ابعثلي الـ 8 صور اللي يخرّجهم، وأنا ندير:
   - نحط اللوقو الأصلي والكتابة العربية بخط Tajawal
   - نحرّك كل صورة (زووم، رايات تتحرك، ضباب، غبرة، الرجال يمشيو)
   - الصوت والإيقاع ← الفيديو كامل 25 ثانية
